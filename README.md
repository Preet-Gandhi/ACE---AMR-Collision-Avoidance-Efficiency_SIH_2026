# ACE---AMR-Collision-Avoidance-Efficiency
**ACE – AMR Collision Avoidance &amp; Efficiency** is a distributed coordination framework for warehouse AMRs, using rule-based decisions, path planning, local communication, collision avoidance, traffic management, task prioritization, and congestion-aware rerouting to improve fleet efficiency and reliability.

## Contributions and git Workflow
Create your own branch using your name (for example, `Aarav`, `Priya`, or `Arjun`) and do all development there. **Test and verify your changes before sending them to `staging` whenever possible.** Before committing or pushing to `staging`, always run `git pull` first so you are working with the latest version. Send completed changes to `staging` for team-wide testing and feedback. If your changes cause issues, remove or revert them from `staging`, fix the problem on your own branch, and send the updated changes to `staging` again. Once `staging` is stable and the changes are ready for release, we will create a PR from `staging` → `main` for final review and approval.
